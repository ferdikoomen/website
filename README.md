# Personal website of Ferdi Koomen

## Install
```bash
npm install
```

## Run
```bash
npm run start
```

## Release
```bash
npm run release
```

This type-checks the code and builds the site to `dist`, ready to upload to S3.
Use `npm run preview` to check the production build locally.

## Project structure
```
src/                    Source of the page, built by Vite
    index.html          Page template (Handlebars)
    templates/          Handlebars partials, usable as {{> name }}
    scss/               Styles, inlined in the HTML on release
    ts/                 Scripts, inlined in the HTML on release
    fonts/              Subsetted fonts (generated by `npm run fonts`)
public/                 Copied to `dist` as-is
    static/images/      Gallery images (generated by `npm run images`)
    static/gfx/         Previews, logos (generated by `npm run images`) and favicons
    static/videos/      Gallery videos
assets/                 Originals of the generated images and fonts, not deployed
plugins/                Vite plugins for Handlebars and inlining CSS / JS
scripts/                Image and font generation scripts
```

## Images
Gallery images, previews and logos are generated from the PNG originals in `assets/`.
Each image is resized to multiple widths and encoded as AVIF and WebP, the browser
picks the best fit using `srcset` and `sizes`. The widths and quality settings live in
`scripts/images.config.mjs`.

To add an image: place the PNG in `assets/images` (3520x2200) and run:
```bash
npm run images
```
Then add it to a gallery with `{{> image filename="name" alt="Description" }}`.

## Fonts
Only the Latin characters of the fonts are used, which makes them ~85% smaller.
After adding a font to `assets/fonts`, run:
```bash
npm run fonts
```

## Hosting (S3 + CloudFront)
- Enable "Compress objects automatically" in the CloudFront behavior so the HTML is served with Brotli / Gzip.
- `index.html` should be revalidated on every request, fonts have a hashed filename and can be cached forever:
```bash
aws s3 sync dist s3://<bucket> --exclude "index.html" --exclude "static/fonts/*" --cache-control "public, max-age=604800"
aws s3 sync dist/static/fonts s3://<bucket>/static/fonts --cache-control "public, max-age=31536000, immutable"
aws s3 cp dist/index.html s3://<bucket>/index.html --cache-control "public, max-age=0, must-revalidate"
```
